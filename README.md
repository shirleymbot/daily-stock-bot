# Daily Stock Bot

## Dependencies

Install yfinance:
```bash
pip install yfinance
```

## Configuration

Set Telegram credentials:
```bash
export TELEGRAM_BOT_TOKEN="your_token"
export TELEGRAM_CHAT_ID="your_chat_id"
```

## Usage

```bash
python3 daily_stock_brief.py
```

## History

- v2.0: Initial release with Yahoo Finance API
- v2.1: Switched to yfinance library for more reliable data
